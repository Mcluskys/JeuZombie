JEU ZOMBIE - FICHIERS OPTIMISES POUR LE WEB

1. Sur GitHub, remplace les fichiers portant le meme nom par ceux de ce dossier.
2. Le fichier zombie.png remplace ton zombie.png actuel.
3. Garde main.py tel quel si celui-ci charge deja musique.ogg et cri_zombie.ogg.
4. Supprime du depot GitHub : zombiememoryweb.apk et zombiememoryweb.tar.gz.
5. Fais Commit changes. GitHub Actions reconstruira le site automatiquement.

Ces images ont ete reduites a une resolution adaptee a l'affichage du jeu et les sons
ont ete compresses en OGG pour reduire le temps de chargement.
